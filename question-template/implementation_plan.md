# Phase 1 — Concept Template Bank

## What We Are Building

A complete **Concept Template Bank** — the foundational layer of the entire platform.

A Concept Template is NOT a question. It is a parameterized, reusable blueprint from which
unlimited exam-standard questions will later be generated by the Question Generation system.

This phase does NOT build the Question Bank. That comes next.

## Template Schema (New Expanded Structure)

Each Concept Template row will contain:

```json
{
  "template_id": "uuid",
  "concept_id": "ref → basic_concepts.concept_id",
  "exam_name": "JEE Main",
  "subject_name": "Physics JEE Main",
  "chapter_name": "Kinematics",
  "topic_name": "Equations of Motion",
  "concept_name": "SUVAT Equations",

  // Template Blueprint
  "template_type": "formula_rearrangement | direct_substitution | logical_trap | multi_concept | reverse_thinking",
  "difficulty_level": "easy | medium | hard | pro | legend",
  "difficulty_number": 1,

  // Variable-Based Design (never hardcoded values)
  "variables": [
    { "symbol": "u", "meaning": "Initial velocity", "unit": "m/s", "range": "0-100", "latex": "u" },
    { "symbol": "a", "meaning": "Acceleration",     "unit": "m/s²","range": "0-20",  "latex": "a" },
    { "symbol": "t", "meaning": "Time",             "unit": "s",    "range": "1-30",  "latex": "t" },
    { "symbol": "v", "meaning": "Final velocity",   "unit": "m/s", "range": "0-200", "latex": "v" }
  ],
  "unknown_variable": "{v}",  // What the question asks to find
  "supported_unknowns": ["v", "u", "a", "t", "s"],  // All allowed unknowns for this template

  // Formula (LaTeX)
  "formula_name": "First Equation of Motion",
  "formula_latex": "v = u + at",
  "formula_rearrangements": [
    "u = v - at",
    "a = \\frac{v - u}{t}",
    "t = \\frac{v - u}{a}"
  ],
  "formula_preconditions": ["Constant acceleration", "Linear motion"],
  "formula_assumptions": ["No air resistance", "Uniform acceleration"],
  "related_formulas": ["s = ut + \\frac{1}{2}at^2", "v^2 = u^2 + 2as"],
  "formula_units": "SI units throughout",

  // Template Structure (the reusable blueprint)
  "stem_template": "A {object} starts from rest and accelerates at {a} m/s² for {t} seconds. Find {unknown}.",
  "context_tags": ["mechanics", "daily_life", "sports", "transport"],
  "question_variants": ["direct", "word_problem", "graph_based", "data_table", "diagram"],

  // Answer Logic
  "solution_approach": "Apply v = u + at. Substitute known variables. Isolate unknown.",
  "solution_steps_template": [
    "Identify known: u = {u}, a = {a}, t = {t}",
    "Apply formula: {formula}",
    "Substitute values",
    "Solve for {unknown}"
  ],
  "common_mistakes": [
    "Forgetting to convert units",
    "Using wrong sign for deceleration",
    "Confusing initial and final velocity"
  ],
  "logical_traps": ["Object may decelerate — check sign of a"],
  "conditional_traps": ["If u=0, object starts from rest"],
  "distractor_logic": "Options designed to catch unit errors and sign errors",

  // Metadata
  "cognitive_level": "knowledge | comprehension | application | analysis | synthesis | evaluation",
  "skills_tested": ["formula_recall", "substitution", "unit_conversion", "logical_reasoning"],
  "prerequisites": ["Basic algebra", "Units and dimensions"],
  "exam_weightage_hint": "~8% of Physics section",
  "estimated_frequency": "appears_every_year | alternate_years | rare",
  "generation_rules": {
    "min_variable_values": { "a": 1, "t": 1 },
    "max_variable_values": { "a": 20, "t": 30 },
    "forbidden_combinations": ["a=0 (trivial)"],
    "integer_only": false,
    "decimal_places": 2
  },

  // Supported Variations
  "supported_variations": [
    "variable_replacement",
    "formula_rearrangement",
    "unit_change",
    "context_change",
    "wording_variation",
    "data_table_format",
    "graph_format",
    "multi_part"
  ],

  // Source traceability
  "source_exam_pattern": "JEE Main PYQ 2019",
  "created_at": "timestamp",
  "version": 1
}
```

## 5 Difficulty Levels

### Level 1 — Easy
- Direct formula application
- Single step, single formula
- Only the unknown variable changes
- No tricks, no hidden conditions
- *Template type:* `direct_substitution`

### Level 2 — Medium
- Formula rearrangement required
- Multi-step solving
- Logical wording, hidden assumptions
- Basic reasoning needed
- *Template type:* `formula_rearrangement`

### Level 3 — Hard
- Logical traps and conditional traps
- Multiple conditions, hidden information
- Case-based reasoning, indirect solving
- *Template type:* `logical_trap`

### Level 4 — Pro
- Multiple formulas, multiple concepts
- Nested reasoning, variable transformations
- Constraint-based, integrated problems
- *Template type:* `multi_concept`

### Level 5 — Legend
- Matches or exceeds hardest PYQ difficulty
- Reverse thinking + chain reasoning
- Multiple hidden assumptions
- Multi-formula, variable dependency
- *Template type:* `reverse_thinking`

## Proposed Changes

---

### Component 1 — Database Migration

#### [NEW] `backend/migrations/001_concept_template_bank.sql`
Create the master `concept_template_bank` table with the full expanded schema above.
Preserve all existing concept IDs as foreign keys.

#### [NEW] `backend/migrations/002_formula_metadata.sql`
Create `formula_metadata` table — stores LaTeX formulas, variables, rearrangements,
preconditions, common mistakes, for each unique formula in the system.

#### [NEW] `backend/migrations/003_template_variations.sql`
Create `template_variations` table — stores all supported variation types
(variable_replacement, unit_change, context_change etc.) per template.

---

### Component 2 — Data Seeding Scripts

#### [NEW] `scripts/seed-concept-template-bank.js`
- Reads all 9 CSV files
- Maps concept IDs from `basic_concepts_rows.csv` as master
- Upserts existing 6,195 templates from `concept_templates_rows.csv` into new schema
- Enriches with difficulty levels (maps `easy/medium/hard` → level 1/2/3)
- Adds `pro` and `legend` stubs for manual/AI completion
- Run: `npm run seed:templates`

#### [NEW] `scripts/generate-template-stubs.js`
- For every concept that has 0 templates (6,867 concepts)
- Auto-generates Level 1 (Easy) stub templates per concept
  using formula metadata + concept description
- Flags stubs for human/AI review with `status: "stub"`
- Run: `npm run generate:stubs`

#### [NEW] `scripts/validate-templates.js`
- Validates every template for required fields
- Checks all LaTeX is valid
- Checks all variable references `{var}` exist in variables array
- Checks concept_id exists in basic_concepts
- Reports coverage gaps per exam
- Run: `npm run validate:templates`
