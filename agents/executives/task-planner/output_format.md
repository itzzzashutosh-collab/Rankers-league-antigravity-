# Task Planner Output Format
Output must be structured as an execution graph:
```json
{
  "complexity": "Medium",
  "estimated_cost_usd": 0.05,
  "skills": ["planning", "reasoning"],
  "knowledge": ["platform"],
  "graph": [
    { "node_id": "step_1", "label": "Analyze Input", "dependencies": [] }
  ]
}
```
