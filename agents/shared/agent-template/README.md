# Standard AI Agent Template Blueprint

This directory defines the operational directives for the agent. Every file contains templates that are dynamically parsed during runtime initialization.

## Layout File Indexes
- `identity.md` — Core persona & department scope definitions
- `mission.md` — Target deliverables instructions
- `responsibilities.md` — Active task handlers
- `decision_rules.md` — Branching logical rules
- `approval_rules.md` — Handshake trigger rules
- `escalation_rules.md` — Error handling escalation limits
- `communication.md` — DM & Broadcast channel patterns
- `personality.md` — Style tone presets
- `ethics.md` — Data safety rules
- `thinking.md` — Reasoning steps layout
- `memory_policy.md` — Reading/writing cache guidelines
- `output_format.md` — JSON/Markdown formatting
- `quality_rules.md` — Confidence self-auditing standards
- `reflection.md` — Post-task self-critique loop
- `security.md` — RLS token authorization checks
